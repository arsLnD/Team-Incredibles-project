# Матрица RACI

Команда **Incredibles**, группа 644, бригада № 1.

| Буква | Значение |
|---|---|
| R | Исполняет задачу. Исполнителей может быть несколько. |
| A | Отвечает за итог. В каждой строке один. |
| C | Консультирует до решения. |
| I | Получает итог, согласование у него не спрашивают. |

`A/R` означает, что менеджер проекта и отвечает за итог, и сам выполняет действие.

| Задача | Аналитик | UX/UI-дизайнер | Тестировщик | Разработчик | Менеджер проекта |
|---|---|---|---|---|---|
| Формирование команды | R | R | R | R | A |
| Выбор способа коммуникации | C | C | C | C | A/R |
| Распределение ролей | C | C | C | C | A/R |
| Сбор и анализ требований | R | C | I | I | A |
| Подготовка отчёта | R | C | C | C | A |
| Создание и настройка репозитория | I | I | I | R | A |
| Поддержание структуры репозитория | C | C | C | R | A |
| Коммиты со своими изменениями | R | R | R | R | A |
| Проверка изменений перед слиянием | C | I | R | C | A |
| Слияние в `main` | I | I | I | C | A/R |

Участники: Гужва Дарья — аналитик, Алымова Виктория — UX/UI-дизайнер, Алоян Натали — тестировщик, Акилина Анастасия — разработчик, Евстигнеев Арсений — менеджер проекта.

Для каждой задачи назначен один ответственный и хотя бы один исполнитель. Так задача не остаётся без владельца и не дублируется между двумя ответственными.
